**Prune 日本語版の最初のリリースです。** [cyb3rl00m/prune-debloater](https://github.com/cyb3rl00m/prune-debloater) 2.0.0 をもとに、日本語表示に対応しました。端末の言語が日本語なら日本語で、それ以外の言語では本家と同じ英語で表示されます。

## 新機能

**日本語表示**
- アプリのすべての画面、メッセージ、ボタン、設定項目を日本語で表示します。
- Prune 独自ルール (348 件のキュレーション済みエントリなど) のパッケージ説明、ロック理由、機能グループの警告、影響、元に戻す方法を日本語で表示します。
- メーカー別のセットアップ手順 (開発者向けオプションの開き方、Xiaomi の「USB デバッグ (セキュリティ設定)」、ColorOS の「権限の監視を無効にする」など) と既知の制限を日本語で表示します。
- 互換性レポートと ADB スクリプトのコメントも表示言語で書き出します。
- コミュニティデータベース (UAD-ng) 由来のパッケージ説明は英語のままです。

## 変更点

- 「Debloat」は日本語表示では「スリム化」と表記します。
- ビルドツールを Gradle 9.9.2 / Android Gradle Plugin 9.5.2 / Kotlin 2.4.21 に更新しました (JDK 17〜25 でビルド可能)。
- README を日本語化しました (英語版は README.en.md)。

## インストールについて

- この APK は fork 用の鍵 (`CN=taketake5656`) で署名されています。
- 本家版 (cyb3rl00m の署名) とはパッケージ名が同じで署名が異なるため、上書きインストールはできません。本家版から切り替える場合は、先に本家版をアンインストールしてください (履歴と設定は引き継がれません)。
- 動作条件は本家と同じく Android 9 以降です。システムパッケージの変更には Shizuku (または root) が必要です。
